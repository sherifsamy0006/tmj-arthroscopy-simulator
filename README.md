# TMJ Arthroscopy Simulator

Static teaching simulator: the left pane shows the arthroscopic lens image, the right pane a live 3D map of where the scope is and where it points, with a guided procedure.

Open: `index.html` (same as `simulator.html`). Release r59.

The joint-wall limit, sliding, zones, bleeding, timings, optics and overlays are illustrative teaching aids. Nothing here is clinically validated.
